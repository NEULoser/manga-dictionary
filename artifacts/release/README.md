# 漫画伴读 · Chrome 离线查词扩展

首期实现：框选当前可见漫画区域 → 本地 OCR → 修改原文 → 日语自动分词及原形还原／英语分词 → 点击词汇查看简体中文释义、假名／音标、词性。结果可以在鼠标附近弹窗与固定侧边栏间切换、关闭。

整句翻译已按要求删除。无需本机辅助程序、Python、Node 或 API Key；不含收藏、导出、上下文推断或跨设备同步。

## 安装和使用

1. 解压交付 ZIP（也可直接使用项目中的 `extension` 目录）。保持所有子目录完整。
2. 打开 Chrome 的 `chrome://extensions`，开启右上角“开发者模式”。
3. 点击“加载已解压的扩展程序”，选择包含 `manifest.json` 的 **extension 目录**，不要选项目根目录或 ZIP。
4. 固定“漫画伴读”图标。打开漫画阅读页面，点击图标，选择日语／英语；日语竖排勾选“日语竖排”，横排取消勾选。
5. 点击“框选图片”，拖动选择当前可见的一个对话框，松开鼠标后自动识别。
6. 如有误识别，修改“识别原文”并点击“重新分词”。点击词汇即可查词。
7. “切到侧边栏／鼠标弹窗”切换展示；关闭按钮或 Esc 隐藏面板，恢复阅读。`Alt+Shift+D` 直接框选；快捷键冲突时到 `chrome://extensions/shortcuts` 修改。

安装即包含全部资源，首次识别无需联网下载。第一次加载模型／分词词典可能较慢；一次尽量选择一个对话框。本机性能、选区大小和字体会影响等待时间，没有 API 费用。

## 默认值与支持范围

- 手动选择原文语言，默认日语竖排。语言、竖排开关、展示方式保存在本机 `chrome.storage.local`。
- 由用户点击图标或快捷键后才在当前页启用；不常驻注入所有网站，不申请全站读取权限。
- 选区以**可见页面截图**裁剪：普通图片、CSS 背景、Canvas，以及可见 iframe 内容均可选；不需要跨域读取原图。长条漫画需要滚动后分段框选。
- 优先用于 koob.one、kox.moe 的实际阅读页，也适用于普通网页阅读器。公开检查中 koob.one 返回 403，kox.moe 导航重定向到 kzo.moe，阅读器入口要求登录，因此**尚未验证两个站点登录后的真实阅读页**。无需依赖网站 DOM，但仍可能受页面全屏、特殊布局或浏览器限制影响。
- 原生 Chrome PDF 阅读器、Chrome 内部页、扩展商店和直接打开的电子书文件不属于首期支持范围。普通网页中的图片式 PDF 阅读器可以尝试可见区域框选。
- 本地 HTML 验收页需要在扩展详情页打开“允许访问文件网址”。也可用任何静态 HTTP 服务打开 `tests/reader.html`；安装后的日常使用不需要服务。
- 不做注音假名去除、艺术字、斜排自动校正。Tesseract 是通用 OCR；小字体、低分辨率、黑底、复杂气泡、注音和拟声字可能识别错误。请收紧选区、放大页面、检查排版选项，或手动修正。
- 英语合并断行和字母之间的行末连字符；可能把真实连字符合并，原文可手动更正。日语去除 OCR 空格和断行。

## 离线资源、费用与隐私

| 资源 | 用途 | 包内数据 |
| --- | --- | --- |
| Tesseract.js 6.0.1 / core 6.0.0 | 浏览器内 WebAssembly OCR | 英语、日语横排、日语竖排 tessdata_fast 4.1.0 |
| Kuromoji.js 0.1.2 / IPADIC | 日语分词、读音和词典形 | 包含完整分词词典 |
| 中文维基词典 / Kaikki | 日语中文释义 | 107,297 个词头（含不同字形，非去重意义数量） |
| ECDICT | 英语中文释义与词形关联 | 58,226 个常用词头，筛选有词频／考试标签／常用词标记的词条 |
| OpenCC.js 1.0.5 | 构建时将释义转为简体 | 不转换日语词头和原文 |

数据来源与许可见 [THIRD_PARTY.md](extension/THIRD_PARTY.md)。词典覆盖、释义和读音存在缺漏；不将未收录词编造为已知结果。维基词典数据包含社区维护内容，不能视为商业校订日汉词典。

- 安装后的 OCR、分词、查词完全离线，不调用外部翻译、AI 或词典服务，无月费或计费 Key。
- 下载与开发准备阶段会联系资源发布网站；安装包已经包含资源，普通使用不需要这些网站。
- Chrome 截图 API 先产生当前标签页的**完整可见截图**，然后在扩展内部裁剪选区。完整截图和选区都只在内存处理，无上传、落盘或查询历史；识别完成后释放图片和画布引用。
- 原文、词汇及查询结果只保留在当前页的面板中；关闭面板会隐藏，点击“清空”或刷新页面会清除。插件不保存截图、原文、页面 URL 或查询记录。OCR 模型与词典常驻内存以加快重复使用，不缓存用户查询数据。
- 设置的清除方式：卸载扩展并重新加载。只有三个本机偏好，没有账户或同步数据。
- `activeTab` 获取用户触发后的当前标签页授权；`scripting` 注入框选和面板；`offscreen` 运行本地 OCR／分词；`storage` 保存偏好。未声明外部可连接接口，也未启用远程脚本。

## 验收

打开 `tests/reader.html`（文件网址需按上文授权，或经静态 HTTP 服务），页面文字画在 Canvas 中，不能直接划选。

| 场景 | 操作和预期 |
| --- | --- |
| 日语竖排 | 选择日语竖排，只框选右侧三列文字（避开边框）。应得到“昨日学校で食べました”或可手动修正的近似结果；顺序从右到左 |
| 分词和还原 | 原文填写“昨日、学校で食べました。”，重新分词，点击“食べ”：原形显示“食べる”，中文含“吃”，读音为“たべる”，词性为“动词” |
| 英语断行 | 选择英语，框选英文图。beautiful 应出现“美丽”，went 应关联 go；输入跨行 `beau-` / `tiful` 后重新分词应合并为 beautiful |
| 人工修正 | 修改原文后旧词块和结果清除；重新分词后按新原文查词 |
| 无结果 | 输入不在词典中的造词，点击后明确提示没有中文释义，不显示旧结果 |
| 面板操作 | 弹窗位置靠近框选终点；可切固定侧栏、关闭、重新打开；Esc 取消框选或关闭面板 |
| 小选区／移动页面 | 选区不足 8 像素明确提示；窗口变化或页面滚动导致坐标变化时提示重新框选 |
| 离线 | 先打开页面再断网；框选、分词和查词继续可用；已有模型全部本地加载 |
| 隐私 | 扩展运行时不请求外部 API；本机存储只有 preferences，不包含截图和查询历史 |

自动测试覆盖逻辑边界、真实词典、扩展运行时的分词和 OCR。实际结果和剩余限制见 [TEST_REPORT.md](TEST_REPORT.md)。合成清晰图片的 OCR 成功不代表真实漫画上的准确率。

## 源码与重新构建

可安装目录 `extension/` 已准备好，日常安装无需构建。主要文件：

- `background.js`：用户触发注入、截图、引擎调度；截图前检查活动标签页。
- `content.js`：Shadow DOM 面板、框选、原文修正、词块及错误提示。
- `engine.html` / `engine.js`：离屏文档、本地 OCR、Kuromoji 分词、离线词典查找；逐个处理请求，切换语言时释放旧 OCR worker。
- `logic.js`：选区坐标与文本正规化；采用截图尺寸／视口尺寸之比，支持缩放和高 DPI。
- `data/`、`vendor/`：预下载 OCR、分词模型和生成的中译词典。

需要重新构建词典时安装 Node.js 20+，执行 `powershell -ExecutionPolicy Bypass -File tools/prepare.ps1`，再执行 `npm run build:dictionaries`。准备脚本需要联网，安装后的扩展不联网。Wiktionary 及 ECDICT 的上游下载地址可能更新，原始文件哈希见 `RESOURCE_LOCK.json`；交付的成品数据不会自行更新。

运行逻辑测试：`npm test`。浏览器集成测试：`node tests/integration.mjs`，需安装 `playwright-core` 并设置 `CHROME_PATH` 指向支持加载未打包扩展及 Extensions.triggerAction 的 Chrome for Testing／Chromium；可设置 `PLAYWRIGHT_PATH` 指向本地 playwright-core 的 index.js。测试会使用独立项目内 profile，不读取日常 Chrome 资料。
